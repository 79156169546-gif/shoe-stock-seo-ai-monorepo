# Enterprise AI Monorepo: SEO-Machine & Shoe Stock Avito AI

Комплексный репозиторий, объединяющий два автономных программных комплекса корпоративного уровня:
1. **Gemini SEO-Machine** — Автономная система генеративного SEO/AEO-продвижения нового поколения на базе Google Gemini и Next.js SSG.
2. **Shoe Stock & Avito AI Machine** — Автоматизированный программный конвейер оцифровки склада (400–500+ пар обуви), студийной предметной съемки через ИИ в едином бутиковом стиле, верификации цен в ритейле и генерации автозагрузки Авито XML.

## 🚀 Быстрый старт

### Системные требования:
* Windows 10/11 x64
* Python 3.11+ (с установленными `fastapi`, `uvicorn`, `Pillow`)

### Установка зависимостей:
```bash
pip install fastapi uvicorn pillow jinja2
```

### Запуск проектов в 1 клик:
* **Запуск склада обуви:** дважды кликните по файлу `Запуск Склада Обуви.bat` (откроется браузер на `http://127.0.0.1:8765`).
* **Запуск SEO-машины:** дважды кликните по файлу `Запуск SEO-машины.bat` (обновится дашборд `Панель.html` и откроется аналитика).

## 👠 Проект 1: Shoe Stock & Avito AI Machine

Программный комплекс, созданный для автоматизации распродажи крупного стока брендовой обуви (400–500 пар) по максимальной цене с минимальными трудозатратами.

### Ключевые возможности:

1. **Входящие («Сырая обувь»):**
   * Drag-and-Drop загрузка необработанных фотографий обуви с телефона (ракурсы + фото фабричной бирки).
   * Поля быстрой фиксации размера, бренда и фабричного артикула.
2. **Конвейер ИИ-обработки (Zero-Hallucination Standard):**
   * **Никаких выдуманных фактов:** ИИ извлекает только подтвержденные данные (значок натуральной кожи на бирке, артикул, реальный каблук).
   * **Студийный визуальный стиль («Миланский Бутик / Тёплый Травертин»):** обувь оформляется на подиуме из натурального травертина с мягким софтбокс-светом, фирменным золотым бейджем бренда, изумрудной плашкой размера и премиальной типографикой без наложений.
   * **Галерея из 4–5 ракурсов:** Обложка с инфографикой, чистый вид 3/4, профиль сбоку, макро фактуры кожи и подошвы.
3. **Умная вилка цен и экономика:**
   * Автоматический расчет 3 уровней цен: **РРЦ в магазине** (12 000–15 000 ₽), **Быстрая продажа** (4 900–5 500 ₽), **Максимальная цена** (6 900–7 500 ₽).
4. **Поиск точной модели в магазинах («Оно / Не оно»):**
   * Прямые ссылки на поиск в **Rendez-Vous, Lamoda, Wildberries, Яндекс Маркет**.
   * Кнопки верификации `[✅ Это она]` и `[❌ Не она]` прямо в карточке склада.
5. **Полное редактирование и перегенерация:**
   * Изменение параметров (цена, сезон, бренд, описание) прямо в модальном окне в 1 клик.
   * Кнопка `[🔄 Перегенерировать фото]` для мгновенного обновления визуала.
6. **Автозагрузка в Авито (XML Feed):**
   * Генерация официального `avito_feed.xml` для работы по тарифу с оплатой за просмотры (CPC) — публикация 500 объявлений за 0 ₽.

## 📈 Проект 2: Gemini SEO-Machine

Полная инженерная система контентного доминирования в органическом поиске (Яндекс, Google, AI-overviews, Perplexity).

### Архитектура и компоненты:
* **База знаний (`knowledge_base/`):** 24 структурированных руководства по семантике, Wordstat API, архитектуре Next.js SSG, GeoDNS, Cloudflare CDN и AEO-оптимизации.
* **Мастер-мануал (`GEMINI_SEO_MACHINE_PRO.md`):** 10 автономных систем и 105 пошаговых механик контентной фабрики.
* **Валидатор ОТК (`validator.py`):** 11 автоматических гейтов качества контента (6 блокирующих) перед публикацией любого материала (проверка фактов, угла отстройки, валидности JSON-LD).
* **Мониторинг (`generate_panel.py` & `Панель.html`):** Автономная веб-витрина состояния проекта, очередей публикаций и ключевых метрик.
