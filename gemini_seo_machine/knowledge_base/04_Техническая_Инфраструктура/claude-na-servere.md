##  01 Забаненный аккаунт сервер не возвращает

Подписка привязана к аккаунту, не к IP. Новый VPS не снимает бан Claude и не создаёт новый аккаунт. Если доступ уже закрыли, ставьте на этот сервер Codex и работайте в нём. Codex CLI входит в подписку ChatGPT. Какой тариф его включает в день покупки, смотрите у OpenAI: состав подписок меняется.

Сервер нужен в двух случаях. Claude ещё жив, но с вашей сети он не пускает или сессия рвётся. Либо вы хотите, чтобы программа крутилась на машине, которая не засыпает вместе с ноутбуком. Я делаю второе.

Что этот гайд не обещает

Датацентровый IP не равен домашнему и ничего не гарантирует. Условия Claude остаются их условиями: [справка по подписке](https://support.claude.com/en/articles/8325609-how-do-i-sign-up-for-the-pro-plan). Чужие истории про баны я здесь не пересказываю и в инструкцию не превращаю.

##  02 CLI стоит на сервере, ноутбук только подключается

Путаница обычно здесь. Есть две разные схемы, и смешивать их не стоит.

Что  Где лежит

Codex CLI и Claude Code  На VPS. На ноутбук их ставить не нужно
Проекты и файлы  На VPS, в каталоге `~/work`. VS Code показывает их как локальные
Подписка  Ваш аккаунт. Вход один раз, в терминале сервера, своими руками
Ноутбук  Окно: SSH или VS Code. Выключили крышку — сервер продолжает работать

Слева только подключение. Программы и файлы — на сервере.

Вторая схема другая: Claude остаётся на ноутбуке, а в интернет выходит через ваш VPN. Для неё отдельный маленький сервер и [гайд про свой VPN](/guides/svoy-vpn/). На ту машину агента не ставьте. Там 1 ГБ памяти, CLI на ней не живёт, а блокировка IP погасит и VPN, и работу.

##  04 Нейросеть ставит CLI и пускает вас через VS Code

Сервер создан, IP записан. Текст ниже вставляете в нейросеть, у которой есть терминал на вашем компьютере: Claude Code, Codex, Grok или DeepSeek. Обычный чат на сайте сервер не настроит, он только объяснит шаги. Бесплатный DeepSeek подходит, если умеет выполнять команды у вас на машине.

В первой строке подставьте свою систему, IP и пользователя из панели хостинга. Чаще всего это `root`.

Промпт CLI на чистом VPS   Копировать

Мой компьютер: [Windows / macOS / Linux].
Сервер: [IP], заход ssh [пользователь]@[IP]. Это чистый сервер под агента. Если на нём уже сайт, VPN, Xray, 3X-UI или незнакомые службы — остановись и покажи, ничего не меняй.

Поставь Codex CLI и Claude Code и доступ с моего компьютера через SSH и VS Code. Делай сам. В подписку меня не входи и токены не проси.

СТАВИМ, оба от имени рабочего пользователя, не root
- Codex CLI, официальный установщик: curl -fsSL https://chatgpt.com/codex/install.sh | sh
- Claude Code, официальный установщик: curl -fsSL https://claude.ai/install.sh | bash
Оба должны находиться в PATH этого пользователя, в том числе в нелогиновом shell: так открывает терминал VS Code. Настольные приложения Claude и Codex не ставь, рабочего стола на сервере нет.

ШАГИ
1. Доступ. SSH-ключ я добавил при создании сервера. Не находишь — спроси путь на моём компьютере, второй ключ поверх старого не создавай.
Заведи пользователя с sudo без пароля. Файл /etc/sudoers.d/90-имя с NOPASSWD:ALL, проверь visudo -cf.
В ОТДЕЛЬНОЙ сессии войди этим пользователем и выполни sudo -n true. Только если прошло — иди дальше.
Закрой root и вход по паролю файлом /etc/ssh/sshd_config.d/00-hardening.conf: PermitRootLogin no, PasswordAuthentication no, KbdInteractiveAuthentication no. В образах Ubuntu файл 50-cloud-init.conf включает пароль обратно, правка главного sshd_config его не перебивает. sshd -t, перезапусти ssh, проверь sshd -T. Алиас сервера добавь в мой ~/.ssh/config.
2. Память. Если RAM около 4 ГБ и swap нет — добавь swap 2 ГБ. На 1 ГБ ничего не ставь.
3. База. DEBIAN_FRONTEND=noninteractive apt-get update и upgrade без вопросов, поставь unattended-upgrades. ufw: открыт только порт SSH, остальное входящее закрыто. Включай ufw после того, как новая сессия пускает.
4. Поставь оба CLI командами выше, в домашний каталог пользователя. Node ставь, только если установщик сам его требует. Проверь от этого пользователя: codex --version и claude --version.
5. Каталог ~/work с правами этого пользователя. Туда я положу проекты.
6. Вход НЕ делай. Не запускай codex login, codex login --device-auth и claude. В отчёте дай две команды, которые я выполню сам по SSH: codex login --device-auth и claude. Код устройства и ссылку входа я в чат не присылаю.
7. Напиши, как подключиться из VS Code: расширение Remote - SSH, идентификатор ms-vscode-remote.remote-ssh, хост = алиас из ~/.ssh/config, открыть папку ~/work. Терминал в этом окне — терминал сервера.

ОТЧЁТ
Версии обеих программ, имя пользователя, алиас, вывод ss -lntup и ufw status, куда класть проекты, команды входа, шаги VS Code. Приватные ключи, токены, пароли и коды входа в чат не выводи. На сервер не ставь VPN, прокси и панели.

##  05 В подписку входите вы, не нейросеть

Когда отчёт готов, подключитесь сами и войдите. Код с экрана в чат настройки не копируйте: переписка с нейросетью — плохое место для входа в аккаунт.

В терминале на своём компьютере: `ssh алиас`. Должна открыться оболочка сервера, без пароля.

* На сервере нет браузера. Сначала в настройках безопасности ChatGPT включите вход по коду устройства. В рабочем пространстве это делает администратор. Затем на сервере: `codex login --device-auth`. Терминал печатает ссылку и одноразовый код. Ссылку открываете на своём компьютере, код вводите там же. В чат настройки код не копируете. Если вход по коду выключен, команда уходит в обычный браузерный вход, и на сервере он не завершится.

* Вход в Claude, если аккаунт жив: `claude`. Та же схема, код устройства вводите у себя.

* В VS Code поставьте Remote - SSH, выберите алиас, откройте `~/work`. Новый терминал в этом окне — уже сервер. В нём снова `codex` или `claude`.

Так выглядит вход с сервера, где нет браузера. Текст подсказки — из Codex CLI, код на картинке пример. Свой код никому не пересылайте, в том числе нейросети, которая настраивала сервер.

Дальше работа выглядит так же, как на ноутбуке, только файлы лежат на сервере. Ноутбук можно закрыть: сессия SSH оборвётся, сервер останется. Завтра VS Code подключится к той же папке.

Claude Code с нуля, если сам инструмент ещё незнаком, — в гайде [«Старт в Claude Code»](/guides/start-claude/). На сервере команды те же.

##  06 Telegram нужен, только если не хотите держать терминал

Это необязательный второй шаг. Я на своём сервере попросил ещё Hermes: он стоит рядом с Codex и отвечает в Telegram, ноутбук для этого не обязан быть включён. Пока хватает VS Code, Hermes не ставьте.

Пример переписки, когда Hermes уже запущен. Имя бота будет ваше.

Бот создаёте вы у [@BotFather](https://t.me/BotFather). Токен в чат с нейросетью не отправляйте. Вставляете его по SSH, когда Hermes спросит сам.

Промпт Hermes в Telegram, по желанию   Копировать

На сервере [алиас], пользователь [имя], уже стоят Codex CLI и Claude Code. Поставь Hermes Agent и приём сообщений из Telegram. Модель и токен бота не выдумывай и в чат не проси.

Ставь официальным установщиком от этого пользователя, не от root:
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Документация: https://hermes-agent.nousresearch.com/docs/
Страница Telegram: https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram

Дальше остановись. Я сам по SSH выберу модель командой hermes model и введу токен бота в hermes gateway setup. Бота я создам у @BotFather. Токен в этот чат не присылаю.

Когда я напишу, что модель выбрана и токен введён:
- подними hermes gateway службой этого пользователя (systemd --user), включи linger, чтобы бот жил без моего SSH и после перезагрузки;
- проверь systemctl --user status;
- напиши, какой лог смотреть, если бот молчит.

Секреты в чат не выводи. VPN, прокси и панели не ставь.

Grok CLI на тот же сервер ставится отдельной просьбой, если подписка xAI есть. В базовый промпт я его не кладу: когда Claude недоступен, людям нужен Codex.

##  07 Готово, если три проверки прошли

Значок в редакторе ничего не доказывает. В терминале VS Code, уже на сервере:

* `curl -4 ifconfig.me` печатает IP сервера, не домашний.

* `codex --version` и, если ставили, `claude --version` отвечают от вашего пользователя. `which codex` не лежит в `/root`.

* Короткий вопрос в пустой папке `~/work` получает ответ. Для Telegram, если ставили Hermes: сообщение боту, ответ при закрытом ноутбуке.

Проверка в терминале VS Code. Адрес 203.0.113.50 учебный: у вас команда должна напечатать IP вашего сервера. Версии программ тоже будут свои.

Что видите  Что с этим делать

Claude пишет, что аккаунт заблокирован  Сервер тут ни при чём. Работайте в Codex на этой же машине
`ifconfig.me` показывает домашний IP  Терминал всё ещё на ноутбуке. Откройте папку через Remote - SSH и проверьте снова
`codex: command not found` внутри VS Code, а по SSH команда есть  CLI поставлен не в PATH нелогинового shell или поставлен от root. Верните нейросеть к шагу 4 промпта
На сервере 1 ГБ, установка падает  Это тариф VPN, не этот. Нужны 2 ядра и 4 ГБ, отдельной машиной
Сервер в Москве или Петербурге  IP российский. Для этой задачи локация за границей
После настройки SSH на сервер не зайти  Консоль в панели хостинга. Пароль закрывают только после проверки входа отдельной сессией, это шаг 1 промпта
Бот в Telegram молчит при выключенном ноутбуке  Служба пользователя не запущена или нет linger. Лог, который нейросеть назвала в отчёте Hermes
