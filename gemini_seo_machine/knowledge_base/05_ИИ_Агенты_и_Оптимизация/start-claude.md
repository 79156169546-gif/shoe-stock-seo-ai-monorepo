Старт в ИИ с агентами: Claude Code и Codex с нуля до первой делегированной задачи
*

На выходе:  на твоём компьютере стоит терминальный агент — Claude Code, Codex или оба; ты вошёл по
подписке, открыл папку проекта в VS Code и отдал агенту первую задачу над своими файлами. Дальше — завод,
второй мозг, коннекторы.

Со стороны кажется, что у меня команда: маркетолог, дизайнер, аналитик, разработчики. На самом деле
работу делает агент, а я ставлю задачи — часто голосом. Шесть проектов, ноль сотрудников. Это не «10
промптов, которые взорвут бизнес». Это карта: где ты сейчас, какой шаг следующий и как проверить, что он
сделан. Часть того, что здесь, продают на вебинарах. Я показываю путь, чтобы ты прошёл его быстрее меня.

Сразу честно, где агенты проседают. Тексты в блог я пишу сам — нейросеть выдаёт усреднённо. Картинок
внутри нет — генерю отдельно. В России нужен стабильный VPN, зарубежная карта и, для Claude, иностранный
номер на регистрацию. Всё это ниже, шагами.

## Зачем агент, если есть чат
01
Чат  Быстрые вопросы. Памяти о тебе нет.    02        Cowork / Work  Файлы и база знаний подключены. Помнит проект и голос.    03         Code / Codex  Руки: файлы, скрипты, боты, деплой. Claude Code и Codex.
Чат — это «обсудить ремонт». Агент — «сделать ремонт». В чате ты копируешь ответ руками и надеешься, что
он не пропустил шаг. Агент работает в твоей папке и на сервере: создаёт файлы, пишет и запускает скрипты,
поднимает ботов, деплоит сайты, чинит поломки — и видит результат своих действий, а не гадает.

Лестница одна и у Claude, и у ChatGPT:  Чат → Cowork / Work → Code / Codex.

Чат  — быстрые вопросы. Памяти о тебе нет, контекст задаёшь заново.

*  Cowork  (Claude) /  Work  (ChatGPT) — тот же чат с подключёнными файлами и базой знаний.

*  Code  (Claude Code) /  Codex  — агент с руками. Живёт в терминале, в VS Code или в десктоп-приложении.

Что это даёт на моей работе: контент-завод каждое утро сам пишет статьи, собирает сайт и публикует;
демон канала скрейпит Telegram и считает аналитику; в трёх окнах параллельно идут три задачи. В чате такое
не собрать. Не живи в чате и не удивляйся, что «нейросеть тупит».

##  01  VPN: одна страна, навсегда

На выходе:  claude.ai и chatgpt.com открываются в браузере, страна не меняется.

Из России Claude и Codex не пускают. Нужен стабильный нероссийский IP: обычный VPN прыгает по локациям,
сервис видит скачки и банит аккаунт. Выбери одну страну (у меня стабильны Нидерланды) и не меняй её — ни в
браузере, ни в терминале. VPN стоит на том компьютере, где будет жить агент, а не на телефоне.

Проверка:  открой claude.ai и chatgpt.com — оба грузятся без «недоступно в вашем регионе».
Не вышло?  Ошибка `App unavailable in region` при установке — VPN выключен или не та страна.
В Цехе — напиши Косте, подключится и поможет.

### Регистрация Claude: телефон, страна, верификация

Без номера телефона аккаунт не создать — приходит SMS. Правила Anthropic жёсткие: номер из поддерживаемой
страны (России и Беларуси в списке нет), не VoIP и не «номер из приложения», один аккаунт на номер.
Как решают:

*

Симка соседней страны  (Казахстан, Армения, Грузия, Кыргызстан, Узбекистан, Турция, Сербия) —
надёжнее всего: номер остаётся твоим, повторная проверка придёт тебе.

*

Аренда номера для приёма SMS  — дёшево и быстро, но номер общий: восстановить доступ по нему
потом нельзя, и это ровно тот тип номеров, который правила запрещают.

*

Чего не делать  — покупать «готовый верифицированный аккаунт»: продавец заберёт доступ в любой
момент, а через его сессию проходят все твои файлы и ключи.

С 8 июля 2026 Anthropic вправе запросить документ и селфи. Просят не всех. Практический вывод один:
не держи рабочие данные внутри аккаунта нейросети  — держи в своих папках (Шаг 9). Тогда потеря
доступа стоит подписки, а не бизнеса.

##  03  Только Windows: Git и Python

На выходе:  в новом окне PowerShell `git --version` и `python --version` отвечают.

Mac и Linux этот шаг пропускают. На Windows оба агента ставятся без Git, но Git даёт Claude Code
инструмент Bash, нужен десктоп-приложению Claude и нужен заводу. Python нужен заводу.

*

Git for Windows:  git-scm.com/downloads/win → установщик → на каждом экране Next, ничего не
меняй (в том числе «Adjusting your PATH environment» — оставь рекомендованное).

*

Python 3.13  — в PowerShell: `winget install --id Python.Python.3.13`. Завод работает на 3.12 или
3.13, выше — нет. Нет `winget` — python.org, при установке галочка «Add python.exe to PATH».

Проверка:  закрой PowerShell, открой новое окно, `git --version` и `python --version` печатают версии.
Не вышло?  Перезагрузи компьютер и проверь снова — PATH подхватывается новым окном. В Цехе —
напиши Косте, подключится и поможет.

##  04  Ставим агентов

На выходе:  `claude --version` и/или `codex --version` печатают версию в новом окне терминала.

Node.js больше не нужен ни одному из них: у обоих свои установщики. Сборки со сторонних сайтов не качай.

### Mac и Linux

Терминал: на Mac Cmd+Пробел → «Терминал». Две команды, по одной на агента:

```
curl -fsSL https://claude.ai/install.sh | bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh

```

Пишет `command not found: claude` — добавь `~/.local/bin` в PATH (установщик печатает готовую
строку в конце) и открой новое окно. На Mac есть и `brew install --cask claude-code` / `brew install --cask codex`.

### Windows — нативно, это основной путь

WSL не нужен. Права администратора не нужны.

*

Открой PowerShell:  Win+X → «Windows PowerShell» или «Terminal». В строке должно быть
`PS C:\Users\…>`. Пункт «(x86)» не открывай — 32-битный, установка упадёт.

*

Claude Code  — вставь и Enter:
`powershell
irm https://claude.ai/install.ps1 | iex`
Дождись «Claude Code successfully installed!».

*

Codex  — вставь и Enter:
`powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
Та же команда потом = обновление.

*

Закрой окно, открой новое  (иначе PATH старый) → `claude --version`, `codex --version`.

Что ставится куда: Claude — `%USERPROFILE%\.local\bin\claude.exe`, обновляется сам;
Codex — `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin`, обновляется той же командой.

Требования: Windows 10 версии 1809 и новее или Windows 11, 64-бит. Codex рекомендует Windows 11,
на Windows 10 работает «как получится».

### Windows — запасной путь: WSL

Нужен, если нативная установка не встала или хочется песочницу Linux для Claude Code. Это Ubuntu внутри
Windows: агенты и завод живут «в Linux», команды — как на Mac.

* PowerShell  от администратора : `wsl --install`, перезагрузка. Откроется Ubuntu, придумай логин и пароль.

* Внутри Ubuntu — команды из блока «Mac и Linux» выше.

*

VS Code: расширение «WSL» (Microsoft), потом из Ubuntu в папке проекта `code .` — VS Code откроется
в режиме WSL, терминал внутри будет Linux.

*

Проекты держи в Linux-папке (`~/projects/…`), а не в `/mnt/c/…` — так в разы быстрее.

Вход из WSL: если браузер сам не открылся, скопируй ссылку из терминала в браузер Windows. Codex в WSL
работает только на WSL 2 (WSL 1 не поддерживается).

Проверка:  новое окно, `claude --version` и `codex --version` печатают версии.
Не вышло?  `claude doctor` покажет, что не так с Claude Code. В Цехе — напиши Косте, подключится и
поможет; скинь скрин ошибки.

##  05  VS Code: одно окно на всё

На выходе:  папка проекта открыта в VS Code, внутри терминал, справа панели агентов.

Можно жить в чёрном терминале (я так и делаю — быстрее). Новичку проще VS Code: там же редактор файлов,
удобно вставлять картинки и копировать текст, а терминал внутри — тот же.

* code.visualstudio.com →  User Installer  (без администратора) → далее по умолчанию.

*

Создай папку под проект, например `Projects\zavod` (на Mac — `Projects/zavod`). В VS Code:
File → Open Folder.

*

Расширения: Ctrl+Shift+X (Mac — Cmd+Shift+X) → в поиске  «Claude Code»  (издатель Anthropic) →
Install;  «Codex»  (издатель OpenAI, называется «Codex – OpenAI's coding agent») → Install.

*

Терминал внутри: Ctrl+`(на Mac — Cmd+`). На Windows там должен быть PowerShell.

Расширения носят свою копию агента и умеют показывать правки бок о бок до применения, редактировать план,
хранить историю. Но для завода нужны именно терминальные `claude` и `codex` из Шага 4 — завод зовёт их
сам, расширению в PATH они не нужны, а заводу нужны.

Проверка:  в терминале VS Code `claude --version` отвечает.
Не вышло?  Расширение не появилось — Ctrl+Shift+P → «Developer: Reload Window». В Цехе — напиши Косте.

##  06  Вход по подписке

На выходе:  оба агента здороваются и знают, что ты на подписке.

Входи через подписку,  не через API-ключ : ключ биллится по токенам мимо подписки (у меня был счёт
$1800 за два дня). Браузер в этот момент — через тот же VPN.

*

Claude Code:  в терминале в папке проекта `claude` → откроется браузер → войди в аккаунт → вернись
в терминал, он поздоровается. Проверка: `claude doctor` без ошибок.

*

Codex:  `codex` → «Sign in with ChatGPT» → браузер → вернись. Проверка: `codex login status`.
Отдельно вход делает `codex login`, выход — `codex logout`.

*

Windows, первый запуск Codex:  он предложит настроить песочницу и один раз попросит права
администратора — соглашайся. Не дали — Codex сам перейдёт на запасной режим песочницы, работать можно.

*

В VS Code  то же самое кнопкой «Sign in» на панели расширения.

Не вышло?  Ошибка после входа `403` — аккаунт без платного плана. Браузер не открылся — скопируй
ссылку из терминала руками. В Цехе — напиши Косте, подключится и поможет.

##  07  Первый час: что написать, когда курсор мигает

На выходе:  разобранная тестовая папка, первый рабочий файл, файл о тебе.

Минуты 0–15. Первая задача — навести порядок.  Создай тестовую папку, скинь туда десяток файлов из
«Загрузок», запусти там агента и напиши:

Посмотри, какие файлы в этой папке, и разложи их по подпапкам по смыслу. Сначала покажи план,
файлы пока не трогай.

Агент перечислит файлы, предложит структуру и спросит разрешение на каждое действие. Всё видно, всё
обратимо — и сразу чувствуется разница с чатом: он не советует, а делает.

Минуты 15–30. Задача про твою работу.  Не код:

Создай файл `клиенты.md` и сведи туда заметки из этих трёх файлов: по каждому клиенту — статус,
последний контакт, следующий шаг.

Правило первой недели: задачи над  своими файлами в конкретной папке . Так виден результат и понятны
границы.

Минуты 30–45. Представься.  В Claude Code напиши `/init` — он изучит папку и создаст `CLAUDE.md`.
В Codex — `/init`, получишь `AGENTS.md`. Продиктуй туда пару абзацев: кто ты, чем занимаешься, над чем
работаешь в этой папке, каким тоном пишешь. Этот файл агент читает сам при каждом запуске — это зародыш
второго мозга из Шага 9. Работаешь обоими агентами — держи оба файла одинаковыми (скажи: «синхронизируй
AGENTS.md с CLAUDE.md»).

Минуты 45–60. Три кнопки.

*  Esc  — прервать агента на полпути. Контекст не теряется, можно уточнить задачу.

*  `/clear`  (Claude) /  `/new`  (Codex) — начать с чистого листа, когда разговор ушёл не туда.

*  `/help`  — список команд. Про остальное спрашивай самого агента: «как в Claude Code сделать X» —
он знает про себя лучше любой статьи.

##  08  Агент спросит разрешение — это нормально

На выходе:  ты читаешь, что подтверждаешь, и знаешь, где режим плана.

У агента есть руки, поэтому перед правкой файла или командой в терминале он спрашивает: разрешить?
Варианты: «да», «да и больше не спрашивать про такое», «нет».

*  Первую неделю читай, что подтверждаешь  — что за файл он меняет, что за команда. Это и есть обучение.

*

«Больше не спрашивать» давай постепенно  — на частое и обратимое: чтение, правки в рабочей папке.
Удаление и команды с интернетом пусть спрашивает всегда.

*

Режим плана — страховка.  Claude Code: Shift+Tab до надписи «plan». Codex: `/plan`. Агент сначала
пишет, что собирается делать, ты читаешь и одобряешь — только потом он трогает файлы. Для всего
страшнее «переименуй файлы» начинай с него.

*

Полный доступ без вопросов  — у Claude флаг `--dangerously-skip-permissions`, у Codex режим полного
доступа в `/permissions`. Новичку не нужны. Я гоняю их только там, где нечего терять: на сервере или в
отдельной папке. На рабочем компьютере с документами — нет.

*

Codex на Windows  держит агента в песочнице: писать может только в папку проекта, в интернет —
с твоего разрешения. Не выключай — это защита, а не помеха.

Простое правило вместо паранойи: работай в отдельной папке под проект. Всё, что агент делает, происходит
в ней — и всё видно.

##  09  Память: файл о себе → второй мозг → документация проекта

SECOND BRAIN  база в Obsidian            STATE     STACK     HOT     INDEX                АГЕНТ  ответ под задачу
На выходе:  агент не спрашивает «кто ты и что за проект» каждый раз.

Главная беда нейросетей — каждый раз вводишь их в курс дела заново. Я закрыл это  вторым мозгом  —
базой знаний в Obsidian, к которой подключены оба агента. Промпт — одна строка, ответ приходит в рамках
проекта: агент уже знает контекст, стратегию и голос.

Как устроено:

*  Хранилище  — папки с текстовыми файлами (Obsidian в облаке, виден и с телефона).

*

Горячее ядро  — несколько коротких файлов, что подгружаются в каждую сессию сами: что в работе,
инфраструктура и указатели на ключи, где остановился, карта «что где лежит».

*

Индекс вместо чтения всего.  Агент смотрит оглавление и открывает только нужный файл.

*  Память дописывается сама.  В конце сессии хук напоминает обновить «где остановился».

Минимальная версия — файл о себе из Шага 7. Кит «Второй мозг» из моего бота ставит остальное одной
командой: каркас, мост памяти, хук — и для Claude Code (`CLAUDE.md`), и для Codex (`AGENTS.md`, хук в
`~/.codex/config.toml`). ⚠️ Хуки Codex работают только после того, как ты подтвердил им доверие — кит
скажет об этом в конце установки.

Документация проекта  — про конкретный проект, а не про тебя. В каждом зрелом проекте одна связка:
файл правил в корне (точка входа: стек, как запускать, правила), `docs/_map.md` (карта документации) и
`docs/changelog.md` (лог по датам, свежее сверху).  Без записи изменение не существует  — новый чат
за десять секунд в курсе. Секреты в документацию не пишем — только указатели, ключи живут в `.env`.

И правило, выстраданное на себе:  держи данные в папках, а не в аккаунте нейросети.  Мне блокировали
Claude — всё, что жило в чатах, пропало. Папки не зависят от блокировок и от того, кто завтра лучше.

## Почему у большинства выходит банальщина

Дело почти никогда не в модели. Качество складывается из четырёх частей:  контекст  (второй мозг),

## Если застрял

Четыре выхода, по порядку:

*  Esc  — останови и уточни задачу. Чаще всего он понял не то.

*  Спроси его самого:  «что ты сейчас делаешь и зачем?», «почему не получается?».

*

Начни чисто:  `/clear` (Claude) или `/new` (Codex) и сформулируй другими словами. Не спорь десять
сообщений.

*

Сломался сам агент  — закрой терминал, открой заново, запусти `claude` или `codex`. Файлы
на месте. Не запускается: `claude doctor` проверит установку и подскажет, что чинить;
у Codex — `codex --version` и `codex login status`.

Ничего непоправимого в первую неделю ты не сделаешь: работаешь в своей папке, каждое действие
подтверждаешь сам.

Не вышло?  Напиши Косте — подключится и поможет настроить стартовое окружение. В Цехе — кнопка

## Чек-лист: что отличает «купил подписку и разочаровался» от «делегирую до 70% задач»

* Не жить в чате: агент с руками, а не окно с ответами.

* Пройти первый час: тестовая папка, задача над своими файлами, файл о себе.

* Собирать контекст: файл правил, второй мозг, документация с changelog.

* Читать, что подтверждаешь; сложное — через режим плана; «пропустить всё» не включать.

* Смотреть лимиты, чистить контекст вовремя, выбирать модель под задачу.

* Экспертизу заворачивать в скилл — свою или взятую у профессионала.

* Результат проверять глазами — без ожидания магии с первого раза.
