# Инструкция по проекту: Gemini SEO-Machine

## Архитектура проекта
Проект представляет собой автономную систему контентного SEO на стеке Google Gemini (Gemini Pro, Flash, Grounding, Imagen 3) + Next.js (SSG) + Python 3.11.

## Структура репозитория
- `GEMINI_SEO_MACHINE_PRO.md`: Полный мастер-мануал по 10 системам и 105 механикам.
- `validator.py`: Скрипт ОТК (11 гейтов качества, 6 блокирующих).
- `generate_panel.py`: Скрипт сборки автономной веб-витрины мониторинга (`Панель.html`).
- `Панель.html`: Интерактивный дашборд состояния сайта и очередей контента.
- `run_seo_machine.bat`: Батник запуска всех рабочих окон в один клик.
- `Запуск SEO-машины.lnk`: Ярлык быстрого запуска системы.
- `knowledge_base/`: Полная структурированная база знаний по маркетингу, SEO и автоматизации (24 руководства в формате Markdown).

### Навигатор по Базе Знаний (`knowledge_base/`):
1. `01_Маркетинг_и_Семантика/`: Анализ ниши, подключение Wordstat API и консолей поиска.
2. `02_Создание_и_Архитектура_Сайта`: Пошаговое проектирование сайта с блогом и SSG-каркасом.
3. `03_SEO_Продвижение_и_AEO`: GEO/AEO-оптимизация под ИИ-поиск, самоаудит сайта, конвейер.
4. `04_Техническая_Инфраструктура`: CDN, GeoDNS, собственный VPN-сервер, развертывание на VPS.
5. `05_ИИ_Агенты_и_Оптимизация`: Управление токенами, хуки, безопасная разработка.
6. `06_Контент_Фабрика_и_Медиа`: Контент-пайплайн, видеомонтаж, индексация медиатеки.

## Правила работы
1. Перед публикацией любого материала обязательно запускать `python validator.py <файл>`.
2. URL-адреса формируются строго латиницей в нижнем регистре без спецсимволов.
3. Каждая статья должна содержать проверенные факты, уникальный угол отстройки от топ-3 и валидную JSON-LD разметку.
